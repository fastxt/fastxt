## Fastxt v0.1.0 is released!
[Fastxt](https://fastxt.app), as a sister project to [Local Native](https://localnative.app), is also a decentralized application for different platforms, currently available on iOS, iPadOS and macOS.

Fastxt Desktop does not use [mac catalyst](https://stackoverflow.com/questions/58916615/how-do-i-build-for-mac-catalyst-x86-64-apple-ios-macabi) as it seems require a different type of rust target.

sandbox sqlite file location
```
rustup override set beta
rustup target add x86_64-apple-ios-macabi
```

<!--truncate-->

For Apple's products, they're using SwiftUI.
There is exploration with GTK, the packaging effort on macOS seems would be high.
Electron is great with all the JavaScript and web development ecosystem, the strength is also its drawback as the dependency is so deep, and packaging release effort is high.

If I want this to be [suckless](https://suckless.org/philosophy), and maintained with 10 years, 20 years and 30 years time horizon (hope by then I am still able to code), it need to be programatic and stick to the mainstream or recommended ways to do things on those platforms to minimize maintenance effort.


## MVLM: Minimal Viable Learning Material
Another motivation is to use this as an example repository to teach younger generation to code.

Swift UI has the concept of stateful variable, binding etc, and double binding was there in ActonScript for Flash developer since 2006. Seems there is nothing new under the sun.

Chasing the tech is endless, see Dart, SwiftUI, Deno.
Simplify require, technology and reduce features. Do one thing but do it well.
