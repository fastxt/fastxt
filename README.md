# Fastxt
[fastxt.app](https://fastxt.app)

Fastxt, as a sister project to [Local Native](https://localnative.app), with very similar design and toolchain, is a decentralized cross-platform application to save and sync your txt in local SQLite database without going through any centralized service.

Fastxt uses **native on-device AI models** to help you organize your text information — privately, without sending data to the cloud.

## On-Device AI

Fastxt leverages the AI capabilities built into each platform:

- **Apple (iOS/macOS)** — Apple Foundation Models for on-device language understanding, summarization, and smart organization
- **Android** — Android App Functions / Gemini Nano for on-device text intelligence
- **Desktop (Linux/Windows)** — Self-hosted LLMs (llama.cpp, Ollama) for local inference

### Roadmap

- Smart auto-tagging based on content
- Semantic search (find by meaning, not just keywords)
- Text summarization
- AI-assisted grouping and categorization
- AI-generated metadata syncs across devices via P2P

# Sub-directories

fastxt-android: Android App

fastxt-ios: iOS and iPadOS App

fastxt-rs: rust code — shared core library plus the cross-platform desktop GUI (`fastxt_desktop`, Iced) for Windows/macOS/Linux

archive: dormant prototypes (fastxt-mac SwiftUI, fastxt-win UWP, fastxt-flutter) — superseded, not built
